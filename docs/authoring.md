# 编写与验收约定

当前各版 plan.md 同时保留范围、实现边界和实际验收记录。新增专题仍按 from-scratch-tutorial-plan 细化；不能把目录创建状态当作教程完成。

每版从上一版的实际检查点开始：展示一个具体输入暴露的问题，运行朴素基线，做一个必要改变，再运行反例与正常用例。新增 helper 必须说明调用者、输入、返回值和副作用，不预建统一检索框架或兼容层。

每版正文包含场景、完整输入输出、精确文件目标、可执行命令、预期结果、故障实验及当前边界。最后汇总完整可运行检查点，不引入此前未讲解的逻辑。计划中的 labs、tests、fixtures 仅在该版实现时创建。

验证覆盖正常、非法输入、失败、边界及代表性执行轨迹。检索任务必须使用固定样例和对应证据；模型相关测试记录模型版本、输入与实际结果，不能将随机输出当确定性断言。

正文默认目标为本版 tutorial.md；实现位于 labs/<专题>/，测试位于 tests/<专题>/。代码与正文共同审核后才记录检查点 commit；本次规划不创建提交。旧检查点必须通过对应 Git commit 或明确保存的检查点代码重放，不能宣称最新源码等同于所有旧版。

每版验收记录实际运行命令、结果、环境、尚未验证的范围。当前 37 个版本均已完成正文、实现及复验；真实模型、生产身份系统和小样本容量外推仍明确列为边界。
