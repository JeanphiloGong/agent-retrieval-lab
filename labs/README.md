# 你的实现区

在这里按教程逐版手写实现。当前没有预填 Python 代码。

从 [01 v0](../tutorials/01-evaluation/v0/tutorial.md) 开始，由你创建 `labs/__init__.py`、`labs/evaluation/__init__.py` 和 `labs/evaluation/validate.py`。后续在同一份代码上增量修改，不需要复制参考区或创建全部未来目录。

固定输入在 `fixtures/`，验收测试在 `tests/`。完整参考答案在 `reference/`，不会自动参与普通的 `labs.*` 导入。

每版通过自己的命令和失败实验后，再更新 [学习进度](../docs/progress.md)，按需要保存 Git checkpoint。具体流程见 [手动构建流程](../docs/learning-workflow.md)。
